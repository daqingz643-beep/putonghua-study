⚠️ 当前环境无法使用录音功能

检测到你是通过 file:// 打开的，这不是安全上下文，浏览器会禁止访问麦克风。

解决方法：把这个文件部署到 HTTPS 网站上，3分钟搞定：

  1. 把这个文件改名为 index.html
  2. 打开 https://app.netlify.com/drop，把文件拖进去
  3. 得到一个 https://xxx.netlify.app 地址
  4. 平板用 Edge / Chrome 打开这个 HTTPS 地址，点录音就会弹授权框

或者用你之前的 GitHub Pages：上传到仓库 → Settings → Pages → 选分支 → 得到 https://用户名.github.io/仓库名/

TTS发音、跟写练习在本地也能用，只有录音跟读需要HTTPS。

⚠️ 麦克风权限被拒绝了，需要手动重置

你之前点过"拒绝"，浏览器记住了这个选择。请按以下步骤重置：

  1. 点击浏览器底部的 「...」菜单
  2. 进入 设置 → 站点设置
  3. 找到 麦克风
  4. 在「已拒绝」里找到本网站，点 清除并重置
  5. 回到本页面，从上往下拉刷新，再点录音会重新弹授权框
